# 行为轨迹校验

行为校验参考极验设计：前端把一次验证交互的完整轨迹（按下、移动、松开、点击序列）随答案提交，
后端统一校验“是不是人”以及“轨迹与答案是否一致”。

## td 报文协议

`td` 使用紧凑文本协议，字段与极验对齐：

```text
m|w|h|s|e|p
```

| 字段 | 说明 |
| --- | --- |
| `m` | 协议版本，当前为 `1` |
| `w` / `h` | 前端视口（容器）尺寸 |
| `s` / `e` | 起始 / 结束时间戳（毫秒） |
| `p` | 轨迹点：`timeMs,x,y,type;timeMs,x,y,type;...` |

坐标使用归一化 0~1，时间为相对起点毫秒。事件类型：

| 编码 | 含义 |
| --- | --- |
| `0` | START 起点 |
| `1` | MOVE 移动 |
| `2` | UP 松开 |
| `3` | DOWN 按下 |

示例：

```text
1|300.6|262.0|1787290676714|1787290683694|0,0.0,0.5,0;21,0.1,0.5,1;...
```

## 压缩传输

轨迹点较多时明文会很长，前端默认使用 gzip + base64url 压缩后再提交：

```text
H4sI...
```

后端 `BehaviorTraceCodec` 自动识别压缩/明文两种格式。

## 校验架构

`AbstractBehaviorValidator` 是统一模板，负责：

1. 解析 `td` 报文
2. 通用规则：协议版本、视口尺寸、耗时上下限、点数下限、时间顺序、坐标范围、相邻点跳跃距离
3. 调用子类校验事件序列
4. 调用子类校验轨迹与答案的关联

具体校验器：

| 校验器 | 校验内容 |
| --- | --- |
| `SliderBehaviorValidator` | 按下 → 移动 → 松开，终点归一化 x 与 `xNorm` 一致 |
| `ClickBehaviorValidator` | 按下/松开成对、点击次数与顺序、坐标、单次点击时长 |
| `RotateBehaviorValidator` | 按下 → 移动 → 松开事件序列（角度由生成器校验） |
| `CurveBehaviorValidator` | 按下 → 移动 → 松开，禁止点击事件；轨迹首尾与答案曲线首尾一致 |

曲线绘制额外由生成器做几何校验：起点/终点必须落在引导曲线首尾标记附近，
且绘制点对期望曲线的覆盖率（默认 60%）达到阈值才通过。

## 风险评分（第二层）

硬规则只能拦截“一眼假”的轨迹；对能伪造贝塞尔曲线、会加抖动的机器人，
还需要第二层统计评分：`DragBehaviorRiskScorer` / `ClickBehaviorRiskScorer`
把多个弱信号加权汇总成 0~1 综合分，超过画像阈值才判定异常，避免单特征误伤。

拖拽（滑块/旋转/曲线）特征：

| 特征 | 含义 | 机器表现 |
| --- | --- | --- |
| `speed-uniformity` | 移动速度变异系数 | 匀速直线 → 异常 |
| `end-deceleration` | 末端速度 / 峰值速度 | 全程不减速 → 异常 |
| `start-pause` | 按下到开始移动的停顿 | 按下立即移动 → 异常 |
| `path-efficiency` | 路径长度 / 直线位移 | 绝对平直 → 异常 |

点选特征：

| 特征 | 含义 | 机器表现 |
| --- | --- | --- |
| `move-uniformity` | 点击间移动速度变异系数 | 匀速移动 → 异常 |
| `dwell-uniformity` | 按下时长变异系数 | 每次点击时长完全一致 → 异常 |
| `interval-uniformity` | 点击间隔变异系数 | 节奏完全一致 → 异常 |
| `duplicate-downs` | 是否存在完全相同的点击坐标 | 精确复现同一点 → 异常 |

样本不足的特征权重自动降为 0，避免 H5/小程序稀疏轨迹被误判；
触摸画像默认阈值也更宽松（`0.8`，Web 为 `0.65`）。

开启方式：

```yaml
captcha:
  behavior:
    enabled: true
    risk-enabled: true
    risk-threshold: 0.65
```

综合分超过阈值时同样返回 `BEHAVIOR` 业务码。

## 分端画像

不同设备的轨迹差异很大，阈值按客户端类型区分：

| 画像 | 适用场景 | 特点 |
| --- | --- | --- |
| 默认（Web） | PC 鼠标 | 采样密集，跳跃阈值严格 |
| `h5` | 手机浏览器 / WebView | 触摸采样稀疏，跳跃阈值放宽，点击更快 |
| `mini_program` | 微信小程序 | 同触摸端，事件来源不同 |

默认阈值：

| 配置 | Web | H5 / 小程序 |
| --- | --- | --- |
| `max-jump-ratio` | `0.5` | `0.9` |
| `point-tolerance` | `0.05` | `0.08` |
| `min-click-duration-ms` | `30` | `20` |

## 配置示例

```yaml
captcha:
  behavior:
    enabled: true
    h5:
      max-jump-ratio: 0.9
      point-tolerance: 0.08
      min-click-duration-ms: 20
    mini-program:
      max-jump-ratio: 0.9
```

未开启时前端可不提交 `td`；开启后缺少 `td` 或校验失败返回 `BEHAVIOR` 业务码。

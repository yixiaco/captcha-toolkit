# 极验风格验证码原型（Vue 3）

模仿极验「行为验证 · 第四代」交互形态的纯前端原型，包含两种验证方式：

- **滑块拼图**：拖动滑块让拼图块对准缺口，误差在容差范围内即通过
- **点选文字**：按提示顺序依次点击图中的目标汉字

滑块支持 7 种拼图形状：经典（右侧凸起、上边与左边内凹）、叶子、三角形、圆形、菱形、星星、爱心，可在验证弹窗内切换，也支持随机形状。

点选文字采用抗 OCR 绘制：无边框、无白色描边，文字颜色从所在位置的背景色采样（相近色相、靠明度差辨认），并叠加旋转、倾斜、半透明与干扰线/噪点，人眼可读但机器识别难度更高。

所有验证图片均通过 Canvas 在浏览器内动态生成，无需任何外部图片资源，离线即可运行。

## 运行

```bash
npm install
npm run dev
```

打开 `http://localhost:5173` 即可体验。

## 目录结构

```text
src/
├── App.vue                      # 演示页（登录卡片 + 验证入口）
├── styles.css                   # 全局样式
├── components/
│   ├── CaptchaModal.vue         # 极验风格安全验证弹窗
│   ├── SliderCaptcha.vue        # 滑块拼图验证
│   └── ClickCaptcha.vue         # 点选文字验证
└── utils/
    └── captchaImages.js         # Canvas 图片生成、拼图造型工具
```

## 说明

- 原型仅用于交互演示，不含任何真实风控逻辑
- 滑块验证的容差为 ±6px，可通过 `SliderCaptcha.vue` 中 `<= 6` 调整
- 点选验证每次会随机生成目标汉字与干扰项，点击顺序错误会重置
